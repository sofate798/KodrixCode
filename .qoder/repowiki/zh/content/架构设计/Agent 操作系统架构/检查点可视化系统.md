## 简介
本系统为 Kodrix Agent OS 的"检查点可视化"能力，提供代码变更的可回滚、时间线查看与差异对比。它通过自动捕获与手动创建检查点，持久化工作区文件快照，并在侧边栏以树形视图展示；同时提供 Webview 画廊进行多检查点对比、逐文件接受/拒绝与批量回滚。**重要更新**：系统已全面升级为异步I/O操作，显著提升了性能和响应性，完全避免了UI冻结问题。该能力与扩展主入口集成，在激活时注册命令、视图与事件监听。

## 项目结构
围绕检查点功能的核心文件组织如下：
- checkpointManager.ts：检查点的创建、列出、恢复、删除、操作日志与自动捕获等核心逻辑（已全面异步化）
- checkpointTimelineView.ts：侧边栏 TreeView 时间线，支持展开查看文件、打开 Diff、右键回滚/删除
- checkpointDiffGallery.ts：Webview 差异画廊，支持选择两个检查点或检查点 vs 当前工作区进行对比、逐文件接受/拒绝、批量操作与回滚
- extension.ts：扩展激活入口，统一注册检查点相关模块
- package.json：声明本地化资源、命令、视图容器与配置项，并包含脚本与测试入口

- 交互层：命令注册、QuickPick、TreeView 菜单、Webview 消息通道驱动用户操作，全部非阻塞

## 详细组件分析

### 检查点管理器（checkpointManager）
**重大更新**：全面升级为异步I/O操作，显著提升性能和响应性

- 创建检查点
  - 收集当前打开的工作区内文本文档，过滤 .kodrix 内部文件与大文件，生成 manifest 并落盘
  - 返回检查点 id，供后续操作引用
  - **异步优化**：所有文件操作使用 `fs.promises.mkdir`、`fs.promises.readFile`、`fs.promises.writeFile`
- 列出与读取
  - listCheckpoints 过滤 auto/ 与 operations.jsonl，按创建时间倒序
  - readCheckpointManifest 读取指定检查点的完整清单
  - **异步优化**：使用 `await fs.promises.stat`、`await fs.promises.readdir`
- 安全恢复
  - restoreCheckpoint 对 manifest 中的 relPath 执行路径穿越防护，仅允许在工作区内恢复
  - **异步优化**：目录创建和文件写入均采用异步操作
- 自动捕获
  - onDidSaveTextDocument 触发 autoCaptureFileSave，将保存的文件快照写入 auto/ 目录，并按 maxEntries 滚动清理
  - **异步优化**：文件统计、读取、写入全部异步化
- 操作日志
  - recordOperation 追加 operations.jsonl，超过大小或行数阈值时滚动保留最近 N 条
  - **异步优化**：文件追加、读取、写入全部使用异步API
- 删除与预览
  - deleteCheckpoint 删除指定检查点目录
  - showCheckpointFilesPreview 打开 Markdown 预览文件清单
  - **异步优化**：目录删除使用 `fs.promises.rm`

## 性能与容量特性
**重大性能提升**：全面异步I/O优化

- 自动捕获滚动
  - operations.jsonl 超过 512KB 或超过 2000 行时滚动保留最近条目，避免无限增长
  - **异步优化**：文件读写操作不再阻塞主线程
- 快照限制
  - 单次快照限制文件数量与单文件大小，防止大工程导致内存/磁盘压力
  - **异步优化**：大文件读取采用流式异步处理
- 视图刷新节流
  - 时间线视图在保存后延迟刷新，降低频繁重绘开销
  - **异步优化**：刷新操作异步执行，不阻塞UI
- 差异计算
  - 画廊基于 manifest 构建文件差异，仅比较必要文件，减少 IO 与 CPU 消耗
  - **异步优化**：文件比较和差异计算全部异步化
- **新增性能优势**
  - 完全避免UI冻结：所有I/O操作均在后台线程执行
  - 提升响应速度：大型项目操作流畅无卡顿
  - 改善用户体验：长时间操作不会阻塞用户交互

## 故障排查指南
- 无工作区
  - 现象：创建/回滚失败提示请先打开工作区
  - 原因：未检测到 workspaceFolders
  - 处理：先打开一个文件夹工作区
- 路径穿越防护
  - 现象：恢复时跳过不安全路径
  - 原因：manifest 中 relPath 包含绝对路径或 .. 段
  - 处理：修复 manifest 或重新创建检查点
- 自动捕获未生效
  - 现象：保存文件未产生新条目
  - 原因：配置关闭或文件属于 .kodrix 内部/过大
  - 处理：检查配置开关与文件大小
- 时间线不刷新
  - 现象：新增检查点后列表未更新
  - 原因：未触发刷新或延迟刷新尚未完成
  - 处理：手动执行刷新命令或等待延迟刷新
- **新增：异步操作相关问题**
  - 现象：操作响应缓慢但无错误
  - 原因：可能是网络I/O或大文件处理导致的正常延迟
  - 处理：检查文件大小和网络状态，异步操作需要一定时间完成
