### Build Release
- 定义：项目在 GitHub Actions 上触发的三平台（Windows x64 / Linux x64 / macOS arm64）构建并发布 Release 的完整流水线，包含并行构建、产物上传、SHA256 校验、SBOM 生成和 GitHub Release 创建。
- 别名：Release 构建、三平台构建

### tsgo
- 定义：Go 版 TypeScript 编译器，用于对扩展进行类型检查；在当前项目中因无法解析超出 rootDir 的 vscode.d.ts 路径而被跳过，类型检查由其他方式单独处理。
- 别名：Go TypeScript 编译器

### 块级检索
- 定义：Kodrix Agent OS 扩展中的代码检索粒度之一，指以语法块（函数/类/方法体）为单位进行 BM25 和向量索引与检索，位于符号级检索之后、文件级检索之前，形成三级检索架构。
- 别名：语法块级检索、CodeBlock 检索

### Checkpoint
- 定义：Kodrix 项目中的代码快照机制，支持创建、回滚和时间线视图展示，已实现异步化和时间线视图功能。
- 别名：代码检查点、快照

### Skill 安装
- 定义：Kodrix 扩展中 Skill 的安装流程，涉及流式大小检查等功能，已在缺陷修复闭环中完成相关修正。
- 别名：Skill 安装流程

### API Key SecretStorage
- 定义：将 API Key 从明文存储迁移至 VS Code SecretStorage 的安全修复项，属于高危缺陷 A-03 的修复内容。
- 别名：密钥存储迁移、SecretStorage 迁移

### 审计总报告
- 定义：项目文档 `docs/项目新发现待修复的缺陷问题审计总报告.md`，记录审计发现的缺陷并按高/中/低危分级，修复完成后清空并标记全部闭环。
- 别名：审计报告、缺陷审计报告

### 修复总文档
- 定义：项目文档 `docs/项目总共已更新修复完善的全部内容.md`，集中记录所有已修复缺陷的详情（日期、要点、涉及文件），按时间顺序追加。
- 别名：修复总报告、修复记录文档
