### Kodrix Code
- 定义：本项目对外产品名称（`nameLong`），简称 Kodrix；基于 VS Code/VSCodium 的深度定制分支，定位为「AI 原生代码编辑器」，集成多 Agent 协作、智能补全、Idea Flow 等能力。
- 别名：Kodrix、Kodrix Code

### Agent OS
- 定义：Kodrix 自研的本地 Agent 运行时与编排层，承载 codebase 索引、语义记忆（Learning）、Crew 并行执行、Idea Flow、Vibe Coding、Checkpoint 等能力，对应扩展 `kodrix-agent-os`。
- 别名：kodrix-agent-os、AgentOS

### Idea Flow
- 定义：Kodrix 面向非专业用户的自然语言→可运行雏形工作流，由 Router 根据任务复杂度分流至 Idea Flow 或 Agent/Spec 路径，并与 Checkpoint 联动形成迭代回退能力。
- 别名：IdeaFlow

### Vibe Coding
- 定义：Kodrix 提供的轻量 Agent 编程入口，通过智能路由把简单意图直接交给 Agent/Spec 处理，后续规划增加迭代式小改与自动 Checkpoint。
- 别名：vibeCoding

### Checkpoint
- 定义：Kodrix 对 Agent 改动进行快照/时间线管理的能力，支持创建、列表、回滚、自动捕获、操作日志与路径穿越防护；待实现可视化时间线与 Diff 画廊审阅。
- 别名：检查点

### Agent Crew
- 定义：Kodrix 的多 Agent 并行执行引擎，支持角色（Architect/Coder/Reviewer/Tester/DevOps）、顺序/并行/审批门流水线、跨 Agent 上下文传递、共享 Memory/Wiki/Spec、DAG 可视化与执行报告。
- 别名：crew、AgentCrew

### Learning Engine
- 定义：Kodrix 的语义记忆系统，当前已闭环 TF-IDF 向量 + 余弦检索 + 时间衰减 + 自动分类 + Learning Dashboard；规划升级为真实 embeddings（本地 transformer 或 Copilot embeddings API）。
- 别名：semanticMemory、Learning 2.0

### 主动上下文感知
- 定义：Kodrix 在用户发送消息时自动分析意图、建议附加 Wiki/Memory/Learning 上下文，并在输入框旁展示 KB/条数/约 Token 摘要的可切换开关。
- 别名：Proactive Context、Context Intelligence

### Wiki 2.0
- 定义：Kodrix 的代码理解产物，从纯静态 AST 目录结构升级为 LLM 生成的模块职责描述与 API 文档，并叠加 Code Smell 标注（过长函数/未使用导出/循环依赖等）。
- 别名：语义 Wiki

### @Codebase
- 定义：Kodrix 的双路径代码引用语法：既可用 Copilot 的 `#codebase`，也可用本地 `kodrix.codebase` 引用，用于向 Agent 注入项目级上下文。
- 别名：codebase

### Skill 市场
- 定义：Kodrix 的技能包分发体系，支持目录/GitHub/URL 三种来源，仓库内示例位于 `marketplace/packages`，由 `kodrix-skills` 扩展负责安装与管理。
- 别名：skills、marketplace

### model routing（模型路由）
- 定义：Kodrix 的模型供应商抽象层，内置 13 个预设供应商并支持 BYOK（Bring Your Own Key），默认供应商为 GitHub Copilot，可在扩展层覆盖。
- 别名：模型路由
