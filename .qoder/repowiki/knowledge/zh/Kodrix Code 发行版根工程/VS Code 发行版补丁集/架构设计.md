本模块是一个纯补丁仓库，不包含可执行代码，所有文件均为 `diff --git` 格式的 patch，由外部脚本在拉取 VS Code 源码后按顺序应用。
- 顶层补丁（如 `00-brand-remove-branding.patch`、`00-build-*`、`10-version-*`、`20-keymap-*`、`30-build-*`、`40-cli-*`、`50-build-*`、`60-security-*`、`80-ui-*`）通过文件名前缀数字控制应用顺序，覆盖品牌替换、构建开关、版本注入、策略库、安全加固等横切关注点。
- 子目录按目标域划分：`linux/` 集中 Linux 架构扩展（ppc64le/riscv64/s390x/loong64）、QEMU、RPM 版本修复、终端/远程/策略等；`windows/` 处理 AppX 打包、右键菜单、更新 URL 与最低系统版本；`osx/` 仅含 UI URL 修正；`alpine/reh/`、`insider/`、`helper/` 分别针对 Alpine RHEL 环境、Insider 通道与通用 helper 设置。
- `patches/user/readme.txt` 说明用户自定义补丁应放入 `patches/user/`，由构建脚本自动拾取并应用到源码树，形成“内置补丁 + 用户补丁”的两层叠加机制。
- 依赖方向单向：补丁只修改上游 VS Code 源码文件（`build/`、`src/vs/**`、`extensions/**`），不反向引用本仓库其他补丁，各补丁保持独立、可单独 cherry-pick。
