模块以 `index.ts` 为入口，通过 `glob` 动态扫描同目录下所有 `.ts` 文件（排除 `index.ts` 与 `utils.ts`），并使用 `createRequire` 加载每个文件的默认导出作为 ESLint 规则，集中挂载到 `rules` 对象后统一导出，使根项目只需引用本插件即可启用全部规则。规则按职责分为两类：`code-*.ts` 适用于全仓库通用检查（如导入限制、可空性、测试约束、资源泄漏等），`vscode-dts-*.ts` 仅作用于 `vscode.d.ts` 类型声明文件（如接口命名、事件命名、Provider 命名、Thenable 使用等）。`utils.ts` 提供 `createImportRuleListener` 等共享 AST 监听器工厂，被多个导入/导出相关规则复用；`tests/` 目录存放各规则的单元测试。构建与类型检查通过 `package.json` 中的 `tsgo -p tsconfig.json --noEmit` 完成，不产出 JS，由上层 ESLint 配置按需启用具体规则。
