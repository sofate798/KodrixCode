- 每个规则独立一个文件，并通过 `export default new class Xxx implements eslint.Rule.RuleModule { ... }` 的形式暴露，包含 `meta.messages`、可选 `schema` 以及 `create(context)` 返回的监听器对象。
- AST 节点匹配统一使用字符串形式的 ESTree selector（如 `'MemberExpression[object.name=/^(test|suite)$/][property.name="only"]'`），而非手写遍历逻辑。
- 错误报告统一通过 `context.report({ node, messageId: 'xxx' })` 配合 `meta.messages` 中定义的消息键进行，避免硬编码消息文本。
- 对 import/export/source 字面量的检查统一复用 `utils.ts` 中的 `createImportRuleListener`，覆盖 `import from`、动态 `import()`、`TSImportEqualsDeclaration`、`ExportAll/Named` 等多种语法。
- 规则文件顶部统一保留 Microsoft 版权头注释块，保持风格一致。
