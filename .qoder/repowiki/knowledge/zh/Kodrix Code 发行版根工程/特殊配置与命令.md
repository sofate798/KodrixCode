开发入口集中在 scripts/ 与根 npm scripts：`npm run compile` 调用 gulp 编译客户端与 copilot 扩展，`npm run build-fast` 仅 transpile 客户端并增量编译 extensions，`npm run smoketest` 启动冒烟测试，`npm run sync-marketplace` 同步 kodrix-skills 目录到 catalog.json，Windows 下通过 debug.bat / build.bat 包装 PowerShell 脚本，Linux/macOS 通过 scripts/code-server 或 scripts/code-web 启动。
