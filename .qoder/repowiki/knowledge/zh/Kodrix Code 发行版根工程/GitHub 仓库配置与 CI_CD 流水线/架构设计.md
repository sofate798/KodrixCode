本模块为纯配置型 leaf 模块，按用途划分为若干子目录与文件：
- `workflows/`：GitHub Actions 流水线集合，按职责分为三类——PR 检查（`pr-check.yml`）、跨平台构建与发布（`ci-build-{linux,macos,windows}.yml` + `publish-stable-*` / `publish-insider-*` / `release.yml`）、辅助任务（`nightly.yml`、`lint-zizmor.yml`、`mod-lock-closed-threads.yml`、`mod-stale-issue-pr.yml`）。发布流程通过 `matrix.os: [ubuntu-latest, windows-latest, macos-latest]` 在三个系统上并行构建产物，再经 `sanity` 阶段冒烟测试后进入 `publish`。
- `dependabot.yml`：仅对 `github-actions` ecosystem 启用每周更新，目标分支固定为 `insider`，冷却期 7 天。
- `CODEOWNERS`：按源码路径映射到 `@kodrix/core`、`@kodrix/local`、`@kodrix/skills`、`@kodrix/agent-os`、`@kodrix/build`、`@kodrix/cli` 等团队标签。
- `zizmor.yml`：针对 zizmor 安全扫描规则做行级忽略（允许 `svenstaro/upload-release-action`）。
- `copilot-instructions.md`：面向 Copilot 的项目上下文与编码规范，描述 VS Code fork 架构、扩展依赖链与 TypeScript/Extension 安全约定。
- `repo-starter-kit.yml`：指向 VSCodium 默认 starter kit 包 `@daiyam/default`。
- `ISSUE_TEMPLATE/bug_report.md`、`PULL_REQUEST_TEMPLATE.md`、`SECURITY.md`：仓库协作模板与安全策略说明。
- `scripts/`：当前为空，预留脚本入口。
依赖方向单向向外：所有 workflow 均 checkout 根仓库并调用顶层 `npm ci` / `gulp` / `npm run test-*`，不引入外部业务逻辑。
