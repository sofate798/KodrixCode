本模块是 VS Code 仓库中按运行时代码路径划分的 npm 依赖入口，包含两个并列的 npm workspace：
- `remote/package.json`（包名 `vscode-reh`）：Remote 宿主侧依赖，引入 Node.js 原生能力（`node-pty`、`ssh2`、`kerberos`、`@vscode/sqlite3`、`@vscode/windows-*`、`@vscode/native-watchdog`、`@vscode/proxy-agent`、`http-proxy-agent`/`https-proxy-agent`、`yauzl`/`yazl`、`tar`、`ws` 等），以及共享的 xterm、tree-sitter-wasm、oniguruma、textmate、1ds 遥测、copilot SDK 等。
- `remote/web/package.json`（包名 `vscode-web`）：Web 工作区侧依赖，剔除所有 Node.js 原生模块，仅保留浏览器可运行的子集（xterm addons、katex、jschardet、codicons、tree-sitter-wasm、oniguruma、textmate、1ds、tas-client）。
两者通过独立的 `.npmrc` 与 `package-lock.json` 管理版本锁定；根级 `Directory.Build.props` 由外部构建系统引用以统一属性。依赖方向单向：上层 `src/vs/code/...` 在编译期根据 `isWeb`/`isRemote` 条件选择加载对应包，本模块不导出任何代码。
