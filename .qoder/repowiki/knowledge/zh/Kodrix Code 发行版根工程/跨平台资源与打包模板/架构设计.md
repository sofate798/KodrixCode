该模块按目标平台组织资源，所有可执行入口均为带占位符的脚本/清单，由上层构建阶段替换后生成最终产物：
- `darwin/bin/code.sh`、`linux/bin/code.sh`、`win32/bin/code.cmd` 是统一的 `code` CLI 入口，均通过设置 `ELECTRON_RUN_AS_NODE=1` 调用 `resources/app/out/cli.js`；macOS/Linux 版本还检测 `$VSCODE_IPC_HOOK_CLI` 将请求转发到 `remote-cli` 子命令。
- `server/` 存放远程服务器端资源：`bin/helpers/browser-*.sh`、`bin/remote-cli/*`、`bin/code-server-*` 以及 `manifest.json`（PWA 描述），用于在远端以 Node 进程运行 VS Code server。
- Linux 子目录包含 `.desktop`、`.appdata.xml`、`mime` 注册、`snap/snapcraft.yaml`、`debian/control.template`、`rpm/code.spec.template` 等打包元数据，配合 `completions/bash|zsh` 完成 shell 补全安装。
- Windows 子目录提供 AppX 包清单 `AppxManifest.xml`、Inno Setup 位图、各语言文件关联图标（`.ico`）。
- 所有模板统一使用 `@@NAME@@`、`@@APPNAME@@`、`@@VERSION@@`、`@@PRODNAME@@`、`@@EXEC@@`、`@@ICON@@` 等占位符，由构建系统注入具体值，使同一份资源可产出多发行版（stable/insiders/oss）。
