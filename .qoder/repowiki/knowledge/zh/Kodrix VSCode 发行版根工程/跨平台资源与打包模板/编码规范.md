- 所有平台入口脚本均以 `ELECTRON_RUN_AS_NODE=1` 模式启动 `resources/app/out/cli.js`，保证 CLI 行为一致。
- macOS 与 Linux 入口脚本在检测到 `$VSCODE_IPC_HOOK_CLI` 环境变量时自动重定向到 `remote-cli` 子命令，以支持远程终端场景。
- 所有可分发模板文件统一使用 `@@XXX@@` 形式的占位符（如 `@@NAME@@`、`@@APPNAME@@`、`@@VERSION@@`），由构建期替换而非硬编码。
- 每个平台目录内按职责划分：`bin/` 放可执行脚本，`bin/helpers/` 放平台辅助脚本，`bin/remote-cli/` 放远程 CLI 包装器。
- Linux 桌面集成通过 `.desktop`、`.appdata.xml`、`mime` 包、`bash-completion`/`zsh` 补全四件套共同声明应用能力。
- Windows 侧为每种常见文件类型提供独立图标资源（`.ico`/`.icns`），并通过 AppX 清单声明文件关联与上下文菜单扩展。
