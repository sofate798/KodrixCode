各子项目需先在其目录下 `npm install`；`smoke` 要求已构建过 VS Code（`scripts/code.sh`/`code.bat`），可通过 `--build <path>` 指定构建产物或自动下载上一稳定版；`unit/node` 通过 `node index.js --run <file>` 单测、`--coverage` 生成覆盖率；`sanity` 必须传入 `--commit` 与 `--quality`；`monaco` 使用 `npm run test` 执行，`npm run esm-check` 校验 ESM 兼容；`componentFixtures/playwright` 使用 `npx playwright test`。
