- CI 工作流统一使用 `actions/checkout@v4` 与 `actions/setup-node@v4`（Node 22 + npm cache），并通过 `concurrency.group` + `cancel-in-progress` 避免重复运行。
- 跨平台构建与发布采用 `strategy.matrix.os: [ubuntu-latest, windows-latest, macos-latest]` 三系统矩阵，产物名以 `${{ matrix.os }}` 区分。
- 扩展测试通过 `matrix.extension` 枚举 `kodrix-agent-os` / `kodrix-local` / `kodrix-skills`，并以 `continue-on-error: true` 保证单个扩展失败不阻断整体 PR 检查。
- 安全扫描在 PR 与 release 两条路径分别执行 `npm audit --audit-level=high` 与 `--audit-level=critical`，并结合 gitleaks 进行密钥泄露检测。
