- 平台相关实现通过 `#[cfg(target_os = "...")]` 条件编译同名模块（如 nosleep_linux/macos/windows、service_linux/macos/windows），由上层统一 `mod` 引入。
- 子命令处理器统一接收 `CommandContext` 与 clap 派生的参数结构体，返回 `Result<T, AnyError>`，错误经 `print_and_exit` 统一输出后退出。
- 每个源文件顶部保留统一的 Microsoft Corporation MIT License 文件头，由 `build.rs` 在构建时强制校验，缺失则直接 `process::exit(1)`。
- 对外 API 通过 `pub mod` + 顶层 `lib.rs` 白名单显式导出，内部辅助模块保持私有（如 `async_pipe`、`download_cache`、`json_rpc` 等）。
