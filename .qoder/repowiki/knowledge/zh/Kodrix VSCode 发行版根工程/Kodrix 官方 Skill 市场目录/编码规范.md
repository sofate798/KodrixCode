- catalog.json 中每个 item 统一包含 id（kodrix.<bundle>）、kind、displayName、description、version、publisher、categories、tags、bundle、installName、icon 字段。
- 每个 Skill 包以 `packages/<bundle>/SKILL.md` 形式提供，文件顶部使用 YAML front-matter 声明 name 与 description，正文用中文描述 When to use / Workflow / Commands。
- bundle 名称在 catalog.json 的 bundle/installName 字段与 packages/ 下的目录名保持一致，作为唯一标识符。
