- 每个扩展拥有独立的 `package.json`、`package.nls.json`、`.vscodeignore` 与可选的 `cgmanifest.json`，遵循 VS Code 扩展包标准结构。
- 需要编译的扩展统一通过 `esbuild.mts` / `esbuild.browser.mts` 调用顶层 `esbuild-extension-common.mts` 或 `esbuild-webview-common.mts` 提供的 `run()` 入口，避免重复配置。
- TypeScript 项目统一继承 `tsconfig.base.json`，启用 strict、noUnusedLocals、noUnusedParameters、noImplicitAny 等严格编译选项。
- 语言语法定义以 Tree-sitter 风格的 `*.tmLanguage.json` 存放在 `syntaxes/` 目录下，并由 `language-configuration.json` 配套声明缩进、括号匹配等规则。
- 多语言文案集中放在 `package.nls.json`（及 `package.nls.zh-cn.json` 等本地化文件），通过 `l10n` 或 `contributes.localizations` 机制加载。
- Node 端与 Browser/Webview 端代码通过 `platform === 'browser'` 条件分支或不同 entry point 分离，Browser 构建中 `process.platform` 被 define 为 `'web'` 且 `path` 通过 alias 指向 `path-browserify`。
