AI 供应商管理

为 Plan / Agent / Code / Fast 指定模型名（须是已添加供应商里的模型，例如 deepseek-flash）。不需要登录 GitHub。

内置供应商只需填写 API Key，并可以追加多个模型名。自定义接口必须选择 OpenAI 或 Anthropic 的 base_url。DeepSeek 示例：OpenAI https://api.deepseek.com，Anthropic https://api.deepseek.com/anthropic，模型如 deepseek-flash、deepseek-v4-pro。
