# Code Review

When the user asks for a code review, analyze the selected or referenced code systematically.

## Output format

1. **Summary** — one paragraph on overall quality
2. **Critical** — bugs, security issues, data loss risks
3. **Suggestions** — maintainability, performance, style
4. **Positives** — what is done well

Be specific: cite file paths and line ranges. Prefer actionable fixes over vague advice.
