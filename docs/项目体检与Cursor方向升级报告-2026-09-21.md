## 六、后续建议（未在本轮实施，按价值排序）

1. **登录 GitHub**（账号 → 登录）：解锁 Copilot 聊天/补全、远端代码库索引、Remote Tunnels 的完整链路；本地模型链路（Ollama 等）无需此步即可用。
2. **dev 模式用 Rust 工具链**（`winget install Rustlang.Rustup`）后，Remote Tunnels 可直接 `cargo run` 构建；或直接用 `build.bat` 打包版。
3. **nls 全量翻译**：当前 4 扩展的 package.json 字符串为中文硬编码，如需英文/多语言，可将字符串改为 `%key%` 占位并维护 `package.nls.json`。
4. **扩展集成测试**：`extensions/*/test` 目录已有用例骨架，可接入 `@vscode/test-electron` 跑 e2e 回归。
5. **代码库索引兜底**：`buildRemoteWorkspaceIndex` 依赖 Copilot 就绪与 GitHub 登录；已跳过时 agent-os 本地索引正常兜底，可考虑把「本地索引优先」做成默认策略，减少对 Copilot 的时序依赖。
6. **Agent Host settings 监听**：如需消除上游 ENOPRO 噪音，可在 `agentHostMain.ts` 仿 `cliProcessMain.ts` 注册 `FileUserDataProvider`（建议跟随上游修复，避免长期分叉）。
