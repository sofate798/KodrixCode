## P1 高危

| # | 状态 | 缺陷 | 位置 | 问题与影响 | 修复说明 |
|---|------|------|------|-----------|---------|
| 1 | ✔ | **回滚无路径校验（路径穿越）** | `checkpoint/checkpointManager.ts` | `restoreCheckpoint` 直接 `path.join(workspace, f.relPath)` 写盘，创建时校验过 relPath，**恢复时未重新校验**。manifest.json 被篡改/损坏时，`../` 可逃出工作区写入任意路径。 | 新增 `resolveSafeRestorePath`：拒绝绝对路径 / `..` / 越界后再写盘。 |
| 2 | ✔ | **ACP JSONL 流式解析跨 chunk 截断** | `acp/acpRegistry.ts` | stdout 按 chunk `split(/\r?\n/)`，一条 JSON 消息被拆到两个 chunk 时前段被当纯文本拼接、后段解析失败，**外部 agent 输出静默损坏/丢失**。 | `stdoutBuf` 行缓冲；`close` 时 flush 尾部未完成行。 |
| 3 | ✔ | **CancellationTokenSource 泄漏** | `agent/agentLoop.ts` | `sendRequest` 抛错时 `cts.dispose()` 只写在成功路径。模型不稳定时每轮泄漏一个 CTS。 | `try/finally` 中始终 `cts.dispose()`，并 dispose 父取消订阅。 |
| 4 | ✔ | **Agent 循环 LLM 请求无超时** | `agent/agentLoop.ts` | `sendRequest` 未传超时，总超时只在每轮循环开头检查。模型端挂起时 `timeoutMs` 形同虚设。 | 按剩余总预算设置请求级 `CancellationTokenSource` 超时（至少 5s）。 |
| 5 | ✔ | **终端命令执行误报失败** | `terminal/terminalAi.ts` + `agentLoop.ts` | 无 shell integration 时 2 秒后 `finish()` 返回 `exitCode: undefined, timedOut: false`，`run_command` 判定 `undefined === 0` → **误报失败**。 | 无 SI 时标记 `incomplete`；调用方按 `timedOut` / `incomplete` / `exitCode` 区分。 |
