# Kodrix — 项目非常有必要新实现的核心功能总报告

> **整理日期**：2026-09-25（更新）
> **资料来源**：原码枢体验提升方案、体检报告「后续建议」、与 Cursor / Windsurf / Qoder / Kiro 差距矩阵
> **定位**：在「已修复缺陷」与「待修债务」之外，列出**必须新做或大幅升级**才能形成差异化壁垒的核心能力
> **原则**：少而硬 — 仅保留经验证仍未闭环且不可替代的能力项；已闭环项不再重复列入

---

## 一、为什么必须新做（一句话）

Kodrix 在 Cursor 式基线能力上已基本齐备；真正拉开差距的缺口不在「再抄一个按钮」，而在：

1. **越用越聪明**（真实语义记忆 + 主动上下文补全）
2. **多 Agent 真协作安全**（冲突检测，而非只开多个会话）
3. **代码理解落地**（LLM 语义文档 / Code Smell，而非纯静态索引）
4. **可信 Agent 闭环**（可视化审阅 + 迭代改进 + 安全回退）

## 三、P0 — 核心壁垒（应立即落地）

### 3.1 Learning Engine 2.0：真实 embeddings 升级

| 项 | 内容 |
|----|------|
| **已闭环** | TF-IDF 本地向量 + 余弦检索 + 时间衰减 + 自动分类 + Learning Dashboard + Instructions 同步 |
| **必须新实现** | ① 真实语义 embeddings（本地 transformer 或 Copilot embeddings API）替代 TF-IDF 哈希向量，提升语义理解精度 ② 交互式仪表盘增强（搜索/筛选/编辑/删除条目，替代当前只读展示） |
| **验收** | Agent 任务中语义检索准确率明显优于纯 TF-IDF；仪表盘可搜/筛/编辑/删除 |

### 3.2 主动上下文感知（Proactive Context）

| 项 | 内容 |
|----|------|
| **已闭环** | 文件打开时语义提示相关 Memory/Learning + 隐式上下文默认开启 + 多层上下文组装 + 状态栏摘要 |
| **必须新实现** | ① Chat 意图检测：用户发送消息时自动分析意图，建议附加 Wiki/Memory/Learning 上下文 ② 输入框旁上下文摘要（KB/条数/约 Token）可一键切换开关 |
| **验收** | 默认路径下用户少手动 `@` 也能带上正确上下文；Chat 发送前可预览并调整上下文 |

### 3.3 Checkpoint 时间线 + Diff 画廊

| 项 | 内容 |
|----|------|
| **已闭环** | 检查点创建/列表/回滚/自动捕获/操作日志/路径穿越防护 |
| **必须新实现** | ① 侧栏/底栏可视化时间线（摘要 + 一键回退） ② 多文件 Diff 画廊（逐文件预览变更） ③ 逐文件接受/拒绝/修改 + 批量操作 |
| **验收** | 多文件 Agent 改动可视觉审阅且可单文件回滚（与现有安全路径校验兼容） |

## 四、P1 — 差异化杀手锏（中期必做）

### 4.1 Agent Crew 同文件冲突检测

| 项 | 内容 |
|----|------|
| **已闭环** | 角色（Architect/Coder/Reviewer/Tester/DevOps）+ 顺序/并行/审批门流水线 + 并行执行引擎 + 跨 Agent 上下文传递 + 共享 Memory/Wiki/Spec + 执行报告 + DAG 可视化 |
| **必须新实现** | 并行 Coder 编辑同一文件时的冲突检测与合并策略（自动合并 / 标记冲突 / 通知用户） |
| **验收** | 两个 Coder 并行修改同一文件不会静默覆盖，冲突可被发现并提示用户解决 |

### 4.2 语义代码理解 + Wiki 2.0

| 项 | 内容 |
|----|------|
| **已闭环** | TypeScript AST 级解析 + 符号表 + 导入图 + 调用图 + 引用热度 + 增量更新 + 多语言支持 + Repo Wiki 基础生成 |
| **必须新实现** | ① LLM 生成模块职责描述与 API 文档（替代纯静态目录结构） ② Code Smell 标注（过长函数/未使用导出/循环依赖等） |
| **验收** | 无 GitHub 登录时本地 Wiki 包含语义级模块文档，质量明显优于纯目录扫描 |

### 4.3 Vibe Coding 深化

| 项 | 内容 |
|----|------|
| **已闭环** | 智能路由（复杂→Idea Flow / 简单→Agent/Spec）+ 快捷模板入口 |
| **必须新实现** | ① 迭代式小改模式（只动相关文件，非全量重建） ② 每次迭代自动 Checkpoint（可回退到任意版本） |
| **验收** | 非专业用户能从一句话到可运行雏形，且可在任意迭代步骤安全回退 |
